# AppScanner design context

## Product and audience

AppScanner is a private, single-user decision-support tool for evaluating Vienna rental listings. Its user repeatedly imports, filters, compares, and revisits listings; the interface should reduce uncertainty and make the next action obvious.

## Direction

- Personality: calm, precise, dense, analytical, trustworthy.
- Layout: desktop-first with a complete mobile experience; never rely on horizontal scrolling for core tasks.
- Theme: light by default, optional dark mode.
- Visual foundation: retain the existing OKLCH/teal palette, current typeface, and Base UI components.
- Signature element: a compact decision strip combining all-in cost, score, data completeness, commute source, and confirmed blockers.
- Hierarchy: prefer sections and dividers over nested cards. Keep decoration subordinate to evidence and decisions.

## Interaction and accessibility

- WCAG AA contrast, visible keyboard focus, logical tab order, 44px touch targets, reduced-motion support.
- Every async action exposes pending, success, and error states.
- Empty states explain the next useful action.
- English and Russian receive equivalent information and controls.
- Unknown data is visibly unknown; it must never look like a confirmed zero.
